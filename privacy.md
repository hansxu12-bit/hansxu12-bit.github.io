# Privacy Policy — FCPC Bot Configuration

1. DATA COLLECTION
To execute tactical operations, patrol schedules, and server moderation, the Bot collects the following minimal Discord data points:
- User IDs and Usernames (For tracking ranks, medals, and infractions)
- Server/Guild IDs (To sync FCPC operational networks)
- Message Content & Reactions (Strictly filtered to detect and catch illegal cat emoji usage)

2. DATA UTILIZATION
Collected data is used solely for the internal management of the FCPC Private Military Company. We do not sell, trade, or share user data with any external third parties. All server logs and user violation records are stored securely within the greed-mod infrastructure.

3. DATA RETENTION & DELETION
User information is held as long as you are active within the FCPC network or until an infraction requires permanent blacklisting. Users wishing to have their non-infraction data purged from the system can contact the FCPC High Command or file a request through an official ticket.
